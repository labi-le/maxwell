# 2026-10-27 — Одинаковая подпись в альбоме один раз

- Решение: при отправке альбома подпись, совпадающая с уже прикреплённой к другому элементу той же группы, отправляется только с первым таким элементом; различающиеся подписи остаются у своих элементов.
- Почему: Telegram показывает подпись каждого элемента альбома. У фото-публикации TikTok без собственного текста все изображения получали одинаковый блок «От …» и «Ссылка», и сообщение выглядело как повторённая подпись без содержания.
- Отвергнуто: терять описания остальных элементов, объединяя их в подпись первого; отправлять такие элементы одиночными сообщениями; убирать подпись у всех элементов, кроме первого, независимо от различий.
- Следствия: различающиеся описания по-прежнему остаются у каждого элемента, кэш `file_id` и лимит подписи 1024 не меняются, повторная доставка из кэша применяет то же правило.
