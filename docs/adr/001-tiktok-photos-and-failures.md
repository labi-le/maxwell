# 2026-10-01 — Фото TikTok и диагностика ошибок

- Решение: видео TikTok оставить на `yt-dlp`; фото читать из `webapp.video-detail.itemInfo.itemStruct.imagePost` на `www.tiktok.com`, загружать из проверенных CDN с альтернативами. Сбои хранить в SQLite `download_failures` (последние 200), только этап, безопасную категорию, хост/путь без query и код завершения.
- Почему: установленный `yt-dlp` не извлекает TikTok-фото; прежний подавленный stderr не позволял установить причину неудачи видео. На ноутбуке первый CDN фото иногда недоступен, запасной работает.
- Отвергнуто: новая зависимость `gallery-dl` потребовала бы установки и сопровождения отдельного экстрактора; сырые логи могут раскрыть cookies, подписанные адреса и параметры ссылок; переписывание асинхронного бота не требуется.
- Следствия: формат страницы и домены CDN могут измениться; журнал сохраняется в существующем volume, а неизвестный текст ошибки приходится диагностировать отдельно. Авторизованные cookies отправляются только на HTTPS-страницу TikTok; CDN получает только User-Agent.
