# 2026-10-08 — Классификация фото X и имя отправителя

- Решение: одним обходом прежних direct/legacy/quoted/unified-card медиа собирать фото и обязательный boolean `has_video` (`video`/`animated_gif` → true); в подписи показывать только экранированный `first_name`, сохраняя `tg://user?id=…`. Заменяет [ADR 003](003-source-post-media-captions.md) только в части имени отправителя.
- Почему: публикации X только с фото ошибочно считались содержащими видео, а username не соответствует выбранному имени отправителя.
- Отвергнуто: угадывать видео по обложкам, обходить медиа повторно, подставлять значение при отсутствии/неверном типе `has_video`, показывать username или фамилию.
- Следствия: порядок и дедупликация фото, описание, параллельная загрузка и ошибки смешанных публикаций сохраняются; успешные фото без видео больше не получают ложный сбой видео. Остальные решения ADR 003, лимит подписи, ссылки и запрет сырых приватных логов неизменны.
